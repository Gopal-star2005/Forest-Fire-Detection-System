A forest fire detection and response system in which six supervised learning models—logistic regression, linear regression, support vector machine (SVM), Ada boost classifier (ABC), decision tree classifier (DTC), and k-nearest neighbors (KNN)—were developed and evaluated for binary classification of fire versus non-fire conditions. Each algorithm was trained using labeled sensor data to predict potential fire events, and comparative analysis showed that logistic regression and SVM provided the highest classification accuracy and consistency across multiple test datasets.
